## 6. build_models.py Behavior and File Rewrites

### replace_block() Function (`build_models.py` lines 351-357)
```python
def replace_block(text, start, end, block, fallback_before):
    pat = re.compile(re.escape(start) + r".*?" + re.escape(end), re.S)
    new = f"{start}\n{block}\n{end}"
    if pat.search(text):
        return pat.sub(lambda _: new, text)
    i = text.index(fallback_before)
    return text[:i] + new + "\n" + text[i:]
```

### CONFIRMED:
- Uses regex with `re.S` (dotall) to match between markers
- If markers NOT found, uses `fallback_before` string for insertion
- **RISK**: Fallback uses string index match—duplicate strings could cause wrong replacement

### Sections Rewritten in index.html

| Section | Markers | Lines Affected | Data Sources |
|---------|---------|----------------|--------------|
| MODEL_PRESETS | `/*MODELS:START*/` `/*MODELS:END*/` | 767-803 | voltage, ah, motor |
| SCOOTERS array | `/*SCOOTERS:START*/` `/*SCOOTERS:END*/` | ~771-802 | all fields |
| Internal links | `<!--LINKS:START-->` `<!--LINKS:END-->` | 526-521 | ids, names |

### File Rewrites Executed by build_models.py

| File | Action | Preserves Manual Edits? |
|------|--------|------------------------|
| `index.html` | 3 section replacements | ❌ Only content outside markers |

| `{id}.html` | 30 files rewritten | ❌ Complete overwrite |
