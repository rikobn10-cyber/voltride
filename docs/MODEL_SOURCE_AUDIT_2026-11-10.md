# VoltRide model-source verification — 2026-11-10

## Scope and method

This is a source audit of the five iScooter entries that were present in Ride Match but absent from the canonical 30-model `models.json` catalog. The purpose is to prevent unsupported specifications from influencing recommendations. Manufacturer-published specifications were compared with the values embedded in `ride-match.html`.

This audit does **not** certify the five AliExpress short links as valid, current, or mapped to the exact manufacturer variant. The short-link destinations could not be independently resolved in this review. Do not treat affiliate commission or product availability as verified.

## Important limitations

1. These are manufacturer-claimed maximum specifications, not independently tested real-world speed or range.
2. W6 is demonstrably region/variant-sensitive; a single generic W6 specification is unsafe for a global recommendation until the affiliate SKU is matched.
3. The four other iScooter entries have manufacturer-published specification matches, but their AliExpress short links were not resolved in this audit. The destination listing, seller, region, price, stock, and commission status remain unverified.
4. This is not a complete source audit of the 30 canonical models. Those still require a model-by-model manufacturer-source review before being described as independently verified.
5. The five iScooter affiliate-only entries remain separate from `models.json`; this change does not silently add them to the canonical catalog.

## Code and regression changes in this review

- Corrected the four source-backed iScooter specification records.
- Corrected W6 to the EU technical-page specification and marked it `eligible:false`.
- Ride Match scoring now filters explicitly ineligible records.
- Regression tests assert the four verified spec sets and ensure W6 cannot appear in recommendations.
- No canonical 30-model `models.json` data was changed.
- No generator, sitemap, canonical, hreflang, or service-worker files were regenerated by this source correction.
